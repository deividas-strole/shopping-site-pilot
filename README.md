## Modern Shopping Site Created by Deividas Strole

Design Highlights:

Glassmorphism header with backdrop blur that appears on scroll
Gradient accents throughout (buttons, text, backgrounds)
Smooth animations - hover effects, product cards that lift on hover, image zooms
Hero section with gradient text and animated background glow
Interactive category tabs with smooth transitions
Product grid with staggered animations and quick view on hover
Gradient feature section at the bottom

Interactive Elements:

Search bar in header
Shopping cart with item count badge
Category filtering tabs
Product cards with hover effects revealing quick view and favorite buttons
Responsive design that works on mobile and desktop
